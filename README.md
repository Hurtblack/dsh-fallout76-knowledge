# 辐射76群聊知识库 · dsh-fallout76-knowledge

[下载安装包](https://github.com/Hurtblack/dsh-fallout76-knowledge/releases/latest) · [Windows 安装说明](docs/WINDOWS-INSTALL.md) · [测试状态](https://github.com/Hurtblack/dsh-fallout76-knowledge/actions)

给 DSH + dsh-napcat-bridge / NapCat 的大肥鱼增加长期游戏知识。参考 [dsh-memewiki](https://github.com/thawline/dsh-memewiki) 的本地词条、检索和上下文注入思路，独立实现自动整理群聊。不会发送 QQ 消息，不修改鲸鱼娘或辐射76群友人设，也不启动 NapCat。

## 能做什么

- 读取已允许会话的新讨论，调用 DSH 中已登录的 DeepSeek，挑选有用的配装、任务解法、机制、版本变化和有解释的黑话。没有值得保留的内容可以不收录。
- 自动保存为“玩家经验”，附讨论时间、来源消息编号及必要原话、平台与版本。程序核对引用确实来自这批消息；**引用存在不等于结论正确**，模型判断仍可能出错。
- 同会话、同标题/平台/版本且正文相同的内容合并来源；同主题不同正文并列标为争议。语义相同但标题不同的条目不保证自动合并；管理员可以纠错或停用。
- 回答时按当前问题检索，自动提供少量相关参考，也注册 `search_fallout76_knowledge` 工具。群之间、私聊与群之间不共享资料；桌面普通会话不自动注入 QQ 知识。
- DSH 设置中的“辐射76知识库”提供搜索、编辑、人工核实、争议/停用状态、修改记录、导出、学习开关、手动回看和游标恢复。

**初始库为空，不是内置完整的76百科，不会自动爬贴吧。** 本版先积累这个群真正讨论过的经验。贴吧、攻略网站、更新公告的联网抓取和交叉核实尚未实现。未收到的消息、历史图片、被桥接层过滤掉的聊天无法学习；本插件只整理消息库中的文本。

## 安装

需要 DSH 原生插件宿主、Node ≥22.13（含 node:sqlite）、已安装 dsh-napcat-bridge。开发与兼容验证以 DSH 0.2.2-rc.1、桥接 0.3.5 为基准。Windows 按实际部署的 DSH profile 安装，详见 [Windows 交接说明](docs/WINDOWS-INSTALL.md)。

```powershell
dsh plugin --profile desktop add "D:\实际目录\dsh-fallout76-knowledge-0.1.2.tgz"
```

重启 DSH，在“设置 → 辐射76知识库 → 学习设置”确认：

- 默认允许会话为空，不会读取任何聊天。请明确添加 `group_你的群号`；其他群和所有私聊保持不学习。
- 消息库默认 `$DSH_HOME/napcat/messages.sqlite`，未设置 DSH_HOME 时使用用户目录 `.dsh`。若桥接使用不同目录，请改成它实际的消息库。
- 知识目录默认 `$DSH_HOME/fallout76-knowledge`，可以改成 FP80 上的绝对目录。**修改目录不会自动迁移已有知识**；先关闭学习并停 DSH，复制旧目录，再改路径。
- 模型默认 `deepseek-account / deepseek-flash`，使用 DSH 中已有账号，不需要新增密钥。若 Windows 的提供方/模型不同，在设置中调整。

首次自动运行只记住起点，不扫描历史。此后每30秒检查一次；每次模型整理之间至少5分钟，默认积累6条真人消息或最后一条消息已安静5分钟再整理，每批最多60条、每条最多1800字符，最多提取4条。每日上限48次（UTC日期）；失败请求也计入并保留进度供重试。模型调用会使用该账号额度。手动“整理最近聊天”也受同一额度上限约束，单次只读取最近一批。

**静默学习依赖桥接已经把普通群消息写入数据库。** 若桥接只收 @ 消息，本插件只能学到这些消息；需要在桥接侧核实接收策略，但不要为测试擅自放开群里发言。学习和机器人是否主动发言是独立功能。

## 数据、纠错与迁移

- `fallout76-knowledge.json`：本机插件设置（在 DSH_HOME 下）。
- `知识目录/knowledge.json`：可读 JSON，包含词条、必要引用、修改记录、学习进度和预算。原子替换保存；最多5000条，达到上限会报错保留进度，不悄悄删除知识。
- 设置中“导出知识”用于查看/备份词条；完整迁移请复制整个知识目录。导出文件不是自动导入接口。
- 跨 Windows/Mac 可复制 JSON，但配置中的绝对路径需按新电脑修改。不同消息库的游标不通用：更换消息库后使用“从最新消息重新开始”。不要让两台 DSH 同时写同一目录。
- 写入期间创建 `.write-lock`；若进程意外退出遗留锁，先确认所有相关 DSH 已停，再检查 `owner.json` 并移除锁目录。插件不会擅自覆盖正在写的库或损坏文件。
- 消息编号不假定递增。以消息时间追踪，并回看2分钟去重，覆盖常见短暂乱序。延迟超过2分钟到达的旧消息可能需要手动回看。
- 120天未更新的条目检索时标为待复核；不会因时间到了自动认定为假。停用词条不再检索，但修改历史保留。已进入模型的旧对话内容无法由本插件追溯撤回。
- 不采集其他私聊和用户画像；模型提示要求忽略个人资料/对AI指令/纯闲聊，但模型筛选不是绝对保证。管理员可在管理页检查、修订或停用误收内容。

## 命令行设置

在解压后的插件根目录，使用 Node 22.13+：

```powershell
node scripts/configure.mjs --data-dir "E:\DeepSeekFish\SharedData\fallout76-knowledge" --group 123456789
node scripts/configure.mjs --disable
node scripts/configure.mjs --enable
```

用 `DSH_HOME` 指向实际宿主数据目录；脚本自动备份已有设置，且不移动知识文件。取消学习后在途结果也不会继续写入。

## 开发与验证

```sh
node --test test/*.test.mjs
node --check lib/index.js
npm pack
```

测试采用真实临时 SQLite 数据库和可控提取模型，覆盖静默学习、随机消息ID/乱序、首轮起点、进度恢复、证据校验、去重冲突、会话隔离、开关/并发/预算、文件保护及 HTTP 宿主鉴权与同源管理。真实宿主与模型验证结果见 [验证记录](docs/VALIDATION.md)。Windows 端仍须确认实际 DSH / 桥接版本、普通消息落库和界面加载。

插件只有读取源数据库、调用模型、维护知识库与注入参考的功能，没有 QQ 发送 API。管理接口要求宿主认证；变更操作同时要求同源 JSON 请求。群友不能通过本插件的工具接口修改配置或将经验升级为“已核实”。
