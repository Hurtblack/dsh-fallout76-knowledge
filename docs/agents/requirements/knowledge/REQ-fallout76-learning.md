## Entry

DSH 设置 → 辐射76知识库；机器人当前 QQ 会话的自动参考与搜索工具。

## Requirements

- 管理员允许的会话收到真人讨论后，可以自动筛选和保存有价值的辐射76文本经验；首次自动启用从当前起点开始，历史回看由管理员主动触发。
- 学习过程不向 QQ 发送消息，不更改现有人设、QQ 登录或群聊发言策略。
- 自动词条保留来源原话、消息编号、时间、平台和版本；经验不得自动标为已核实。不存在于当前批次的引用不得入库。
- 相同会话的相同主题和正文合并来源；同主题不同说法保留并标为争议，允许人工更正、核实和停用，保留修改记录。
- 回答只参考当前已允许会话的知识，群之间、私聊与群之间互相隔离；没有命中时不注入无关资料。停用词条不用于后续检索。
- 管理员可搜索、导出、配置允许会话、目录、模型及整理频率，暂停学习；未登录宿主或跨站请求不能管理知识。
- 失败时不推进本次学习进度，重启保留进度和每日额度计数；关闭学习后不再保存未完成的整理结果。原始知识文件损坏或有并发写入时不得擅自覆盖。
- 知识可作为文件跨系统迁移；更换电脑后可调整本机路径和学习起点，不自动共享个人会话知识。

## Scenarios

| Condition | Operation | Result |
| --- | --- | --- |
| 指定群有新游戏经验 | 后台自动整理 | 保存带原话的玩家经验，不发QQ群消息 |
| 模型引用不存在的原话 | 尝试入库 | 拒绝本批，保持原学习进度 |
| 群提问与私聊知识同名 | 检索 | 不返回私聊资料 |
| 同主题出现不同结论 | 再次学习 | 两种说法都保留并标争议 |
| 管理员停用旧攻略 | 后续检索 | 不再返回停用条目 |
| 插件重启 | 继续学习 | 不重复处理已完成消息 |
