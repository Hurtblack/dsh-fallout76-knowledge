## Requirements

- AstrBot 组件默认关闭；只在配置的一个 QQ 群、一个平台实例和明确的机器人账号范围内学习和使用风格。可复用 group_chat_plus 已有目标群历史，接受目标群脱敏导出，并持续处理实际收到的新群事件。不会改变任何群发送策略。
- 排除自身和配置中已知机器人的输出。可参与上下文的简短接话和媒体反应可用。已知引用保留目标消息 ID；不能确定的引用不猜测；相邻对话不冒充显式引用。
- 句长、口语、接梗、请教、承认错误、表情反应和兴趣偏好有足够样本证据才生效。表达和兴趣只能从有限选项生成，学习输出不包含群友原话、用户身份、媒体地址或游戏数值。风格和事实库独立，身份、主人识别、隐私、权限和知识核验继续使用既有规则。
- 风格增量通过校验后自动应用，只向目标群请求附加一段有限长度的当前风格，不把多个版本叠进一次请求。没有合格档案、插件停用或其他会话时不注入。DSH 知识、人工修订、旧游标和旧预算独立保留。
- 版本保留来源、差异和当前设置；回滚保留历史、游标和每日评估额度，冻结自动应用直到主动恢复。重启不重复处理相同消息，学风格不调用模型 API。
- 本组件只支持进入 AstrBot 请求钩子的回复链，不代替 QQ 接入、群聊调度、长期记忆、发送、权限或知识核验。媒体学习是反应类别、语境和可用时的脱敏素材标识，不解析缺失的图片，也不下载或发送素材。

## Verification

`astrbot/tests/test_style.py` 测试样本和作用范围、风格生效、回滚和请求修改；`verify_chain.py` 用单独提供的本地 group_chat_plus 源码离线校验实际重写钩子。用户聊天片段回放和 Windows 限制见交付的回放与升级文档。
